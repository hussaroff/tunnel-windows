**Tunnel** объединяет VPN-сервис и клиент для собственных подключений. Начните с сервера из каталога, импортируйте личный конфиг или добавьте подписку своего провайдера. Управление соединением, маршрутами и аккаунтом остаётся в одном приложении.

В основе — **Xray, Mihomo и AmneziaWG**. Можно выбрать подходящий протокол для своей сети, переключить сервер и настроить, какие приложения и сайты должны использовать VPN.

## Возможности

| Возможность | В приложении |
| :--- | :--- |
| **Готовый каталог** | Серверы Tunnel для Windows, поиск, категории и личные подключения в отдельной группе. |
| **Ваши серверы и подписки** | Ссылки нод, Xray JSON, WireGuard / AWG `.conf`, подписки Clash / Meta и совместимые ссылки популярных панелей. |
| **Раздельные маршруты** | Выбор приложений из списка с поиском, домены и исключения, GeoIP / GeoSite для Xray и Mihomo. |
| **Контроль соединения** | Kill Switch, DNS, MTU, предпочтение IPv4 / IPv6 и переподключение при изменении сетевых настроек. |
| **Задержка без ожидания списка** | Каждый результат появляется сразу. Сортировка по ping перестраивает список по мере проверки. |
| **Ежедневное удобство** | Синхронизация, обновление подписок, трей, автозапуск, автоподключение и сохранение состояния интерфейса. |

## Загрузка и установка

Сборки доступны в [GitHub Releases](https://github.com/hussaroff/tunnel-windows/releases). 

| Сборка | Система | Установщик |
| :--- | :--- | :--- |
| **x64 · Intel / AMD** | Windows 10 / 11, 64 бита | `Tunnel-Setup-x64.exe` |
| **ARM64 · Preview** | Windows 11 на ARM | `Tunnel-Setup-arm64.exe` |

1. Установите подходящую сборку. Права администратора нужны для установки сетевой службы.
2. Войдите в аккаунт или выберите **«Продолжить как гость»**.
3. Выберите сервер в каталоге либо добавьте собственный конфиг или подписку.
4. Нажмите **«Подключить VPN»**.

<details>
<summary>Системные требования и статус ARM64</summary>

- Один установщик x64 подходит и Intel, и AMD. Интерфейс использует Microsoft Edge WebView2.
- В ARM64-сборке VPN-ядра и драйверы нативные; интерфейс и управляющая служба работают через эмуляцию x64 в Windows 11. Сборка предназначена для тестирования: полная проверка VPN на реальном ARM-компьютере ещё предстоит.
- Windows 7 / 8 / 8.1, 32-битная Windows, Windows RT и Windows 10 ARM не поддерживаются.
- Тестовые установщики Tunnel пока не имеют подписи издателя Authenticode.

</details>

## Подписки и личные подключения

**Добавьте ссылку — название и серверы загрузятся автоматически.** Для совместимой подписки Tunnel показывает остаток трафика, срок действия, сообщение, сайт и контакты провайдера, если эти данные передаются. Группы и автоматический выбор поддерживаемого профиля сохраняются: используйте выбор провайдера или подключайтесь к конкретной ноде.

| Источник | Поддержка |
| :--- | :--- |
| **Xray** | VLESS, VMess, Shadowsocks, Trojan, Hysteria2, SOCKS5, HTTP(S); ссылки и JSON-конфигурации. Для личной ноды доступно редактирование JSON. |
| **WireGuard / AmneziaWG** | Стандартный текст конфигурации и импорт `.conf`. |
| **Mihomo** | Совместимые Clash / Meta-профили, группы и дополнительные протоколы, включая TUIC и AnyTLS. |
| **Ссылки подписок** | HTTP(S), `tunnel://`, `happ://`, `clash://`, `mihomo://`, `flclashx://` и поддерживаемые перенаправления. Совместимые форматы Remnawave, 3x-ui и других панелей. |

Зашифрованные ссылки Happ не поддерживаются. Серверы каталога Tunnel и пользовательские подписки разделены. Добавить новое подключение можно при работающем VPN; выбор другого сервера или ноды запускает переключение.

## Маршрутизация и защита

Выберите **«Через VPN»** или **«Напрямую»** для приложений и сайтов. Приложения доступны в списке с поиском, для сайтов поддерживаются домены, маски вида `*.example.com`, IP-адреса, подсети и GEO-правила. Базы GeoIP / GeoSite `.dat` можно добавить из файла или по ссылке с отображением прогресса загрузки.

Настройки **Xray** и **Mihomo** сохраняются отдельно; исключения имеют приоритет. **WireGuard / AmneziaWG не применяет эти правила раздельного туннелирования.**

**Kill Switch** сохраняет блокировку при сбое туннеля и во время защищённого переподключения. DNS, MTU и выбор семейства адреса сервера настраиваются с учётом ядра; по умолчанию используются параметры профиля и стандартные настройки. Изменения активного соединения применяются с переподключением.

<details>
<summary>Аккаунт, синхронизация и данные устройства</summary>

- Можно начать как гость, затем зарегистрировать аккаунт с сохранением доступа. В профиле доступны почта, восстановление пароля, просмотр авторизаций и отзыв остальных сессий.
- Личные подключения и ссылки подписок синхронизируются с аккаунтом Tunnel. Предусмотрены синхронизация при запуске после входа, суточное обновление и ручной запуск; для подписок учитывается интервал провайдера.
- Локальные токены и конфигурации защищены Windows DPAPI. Для управления доступом сервис получает стабильный ID устройства и сведения о клиенте. Провайдер подписки получает производный HWID, платформу, версии Tunnel и Mihomo; токены Tunnel ему не передаются.
- При каждом запуске приложение проверяет обновления. Уведомление в боковом меню показывает версию и важность обновления.

</details>

## Free и Premium

**Free** позволяет использовать доступные бесплатные серверы Tunnel в пределах квоты аккаунта и устройства. **Premium** снимает квоту трафика Tunnel на серверах, доступных по активному тарифу. **Совместный Premium** добавляет управление группой, участниками и дополнительными местами.

**Для личных серверов и пользовательских подписок Tunnel не устанавливает квоту трафика.** Условия вашего провайдера продолжают действовать. Лимит одновременно работающих VPN-устройств определяется типом доступа и настройками аккаунта, в том числе для личных подключений. Актуальные тарифы и условия отображаются в приложении.
